从一个请求，到一条用户记录。

注册一个测试账号，再验证它的密码。浏览器提交表单，C++ 工作线程处理业务，MySQL 保存用户与密码哈希。

仅供本机学习 HTTP 不加密传输，请勿使用真实网站的密码。验证成功只表示账号密码匹配，不创建登录会话，也不授予访问权限。
01 / CREATEPOST /register

创建测试账号

密码经过随机盐与 PBKDF2 处理后存入数据库，不保存原始密码。

1–64 字节；用户名按字节区分，大小写不同视为不同账号。

8–128 字节。中文等字符可能占多个 UTF-8 字节。

提交后将在这里显示注册结果。

02 / VERIFYPOST /login

验证账号密码

读取已保存的盐与计算结果，重新计算并比较，不需要解密密码。

输入网站测试账号，不是连接 MySQL 的管理员或学习账号。

错误密码和不存在的用户会得到相同的验证失败提示。

验证结果将显示在这里，不会跳转到新页面。

这个页面背后的处理流程

  1. 01 · HTTP 请求接收完整表单，解析 username 与 password。
  2. 02 · 工作线程执行 AuthService，计算密码或校验已有记录。
  3. 03 · MySQL 与响应参数绑定执行 SQL，归还连接，再返回 HTTP 结果。
MyWebServer · 理解数据流，而不是背接口使用认证功能前需以 MYWEB_AUTH=1 启动服务
